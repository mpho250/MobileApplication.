# Mobile Application – User Stories

## User Story 1: User Registration
As a new user, I want to create an account using my username, email, and password so that I can access the application.

## User Story 2: User Login
As a registered user, I want to log in using my email and password so that I can access my account.

## User Story 3: Home Screen
As a user, I want to view the home screen so that I can easily explore the application's features.

## User Story 4: View Details
As a user, I want to select an item and view its details so that I can access more information about it.

## User Story 5: Save Favourites
As a user, I want to save items to my favourites so that I can easily find them later.

## User Story 6: Local Storage
As a user, I want my saved information to remain available after closing and reopening the application so that my data is not lost.

## User Story 7: API Integration
As a user, I want the application to retrieve information from an external API so that I can access updated information.

## User Story 8: Settings
As a user, I want to access the settings menu and manage my application preferences so that I can customise my experience.

## User Story 9: Notifications
As a user, I want to receive notifications so that I can stay informed about important updates from the application.
